# Парный замер oxide_parse v8.2.1 и v8.3

v8.2.1 взята из коммита `36112e0`. v8.3 взята из рабочей копии с исправлениями.
Обе сборки release/full, Windows x64, Rust 1.99.1 и один CPython 3.13.7.

Для каждого сценария выполнены 16 раундов. В половине раундов порядок был ABBA, в половине BAAB, где A — v8.2.1, B — v8.3. Порядок сценариев перемешивался. Два наблюдения каждой версии усреднялись внутри раунда. Время включает извлечение и создание Python-результата. Старт процессов, компиляция плана, генерация HTML, сборка мусора и проверка результатов вне таймера.

Входные байты и результаты попарно сверены по SHA-256. Бинарные расширения имеют разные хэши. Конфигурация не фиксировала частоты CPU или фоновую нагрузку.
