# oxide_parse v7 против v6: парный замер

ПК: Intel N97, 4 ядра / 4 потока, 16 ГБ RAM. Обе версии измерены заново на одном ПК в одном прогоне.

ОС: Windows-11-10.0.26200-SP0. Python: 3.13.7 (tags/v3.13.7:bcee1c3, Aug 14 2025, 14:15:11) [MSC v.1944 64 bit (AMD64)].

## Методика

100, 1000 и 10000 товаров, каждый размер с noise и без. HTML и схема одинаковы у обеих версий. Noise добавляет 110 байт неиспользуемой разметки на товар.

v6 — сохранённый установленный release/full из коммита a110cf3; его SHA-256 совпадает с модулем из предыдущего отчёта v6. v7 — новая сборка release/full с теми же настройками. Каждый пакет загружается в отдельный постоянный процесс того же Python. Во время таймера активен только один процесс; компиляция параллельно не выполнялась.

Один прогрев на комбинацию. Семь глобальных раундов: в каждом перемешиваются шесть сценариев, затем группы реализаций. Для каждого движка вызовы v6/v7 соседние, порядок случайный; внешние библиотеки измеряются один раз в каждом раунде сценария. Перед каждым вызовом пауза 0.25 с. Это снижает зависимость от фиксированного порядка, но не устраняет троттлинг и нагрузку Windows.

Замер внутри worker: parse + extract + создание Python-объектов. Планы скомпилированы заранее. Импорты, HTML, сборка, IPC, gc.collect(), проверка и удаление результата вне таймера. GC включён. После каждого вызова проверяются все поля всех товаров по независимо сформированному ожидаемому объекту.

Всего 420 измерений: 252 для oxide_parse (2 версии × 3 движка × 6 сценариев × 7 повторов) и 168 для внешних библиотек. Прогревы не включены.

Для scraper медиана ниже примерно на 5% без noise и на 10% с noise. ## Ограничения

Это один прогон синтетической схемы на рабочем ПК. Температура, частоты, планировщик и фоновые процессы не фиксировались. Из небольших различий и 7 повторов нельзя делать вывод о статистически доказанном ускорении. Числа из старого отчёта v6 напрямую не используются для оценки прироста: базовая v6 измерена повторно рядом с v7.

Тест извлекает список карточек. Ускорение раннего завершения stream для схем только из одиночных полей и асимптотика adaptive отдельно этим тестом не измеряются. JSON и XPath также не входят в эту HTML/CSS-схему.

## Проверки и воспроизведение

39 Rust-тестов, 21 Python-тест, mypy, семь примеров. В архиве исправлен отсутствующий импорт трейта Store в Rust-тесте; настройки release/full и одинаковая форма результата бенчмарка сохранены.

```powershell
uv run python -u benches/bench_compare.py --baseline PATH_TO_V6 --candidate PATH_TO_V7 --sizes 100 1000 10000 --repeat 7 --cooldown 0.25 --output benchmarks/new-comparison/results.json
```

PATH_TO_V6 и PATH_TO_V7 — каталоги с самостоятельной папкой oxide_parse, содержащей Python-файлы и соответствующий release .pyd. Для воспроизведения нужны сохранённые пакеты обеих версий; они не добавлены в Git. results.json содержит хеши пакетов/нативных модулей/исходников, версии зависимостей, все результаты и фактический порядок вызовов. run.log содержит прогресс.

Версии внешних библиотек: beautifulsoup4 4.15.0, lxml 6.1.3, parsel 1.12.1, selectolax 1.0.2.
