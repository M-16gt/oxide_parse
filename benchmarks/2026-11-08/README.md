# Локальный бенчмарк oxide_parse v3 — 8 ноября 2026

ПК: Intel N97, 4 ядра / 4 потока, 16 ГБ RAM (15.75 GiB по данным Windows).
ОС: Windows-11-10.0.26200-SP0. Python: 3.13.7 (tags/v3.13.7:bcee1c3, Aug 14 2025, 14:15:11) [MSC v.1944 64 bit (AMD64)].

Замерены 100, 1000 и 10000 товаров, каждый размер с noise и без. Noise добавляет 110 байт неиспользуемой разметки после каждого товара. Все реализации извлекают одинаковый объект с заголовком страницы и полным списком товаров. Равенство результатов проверяется на прогреве и после каждого замера.

Один прогрев и семь измерений на реализацию в каждом сценарии. Порядок реализаций перемешивается перед каждым раундом с seed=20261108. Сценарии выполняются последовательно. GC включён; gc.collect() вызывается перед каждым измерением вне таймера. Проверка результата и освобождение возвращённого объекта выполняются после остановки таймера.

Время включает разбор HTML, извлечение и создание Python-результата одного документа. Планы oxide_parse компилируются заранее. Генерация HTML, импорт, компиляция планов и проверка результата в измерения не входят. Здесь измеряется Python API. Чистый Rust и extract_many требуют отдельных замеров.

Сборка настроена как release + full. SHA-256 загруженного расширения: `0f28a65e59bb32d7364fe6c44cd8d029a6ce49c9359a7b307898a14277cd0f8d`. Измерялся рабочий код v3 до коммита, базовый коммит: `5d9a92dde51cccfaee04c61710834c9beaa97edf`. Хеши исходников и все отдельные измерения сохранены в results.json.

Это один полный прогон на рабочем ПК под Windows. Нагрузка ОС, температура CPU и планировщик не изолированы. Для оценки разброса приведены min/max. Результаты относятся к этой синтетической схеме и могут отличаться на других страницах.

## Повторение

```powershell
uv sync
uv run python -u benches/bench_suite.py --sizes 100 1000 10000 --repeat 7 --output benchmarks/new-run/results.json
```

results.json содержит 294 отдельных измерения, порядки вызовов, версии, параметры запуска и хеши кода. run.log содержит вывод прогона.
